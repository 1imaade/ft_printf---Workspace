# 03: Live Coding Drills for `ft_printf`

Common functions and live coding tasks requested during peer evaluation:

1. **Write `ft_puthex`**:
   - Takes an `unsigned int` or `unsigned long long` and prints it recursively in hexadecimal (`0123456789abcdef`).
   - Counts and returns the total number of characters printed.

2. **Write `ft_putnbr_base`**:
   - Generic base converter.

3. **Explain Argument Extraction**:
   - Live code the loop parsing the format string character by character.
